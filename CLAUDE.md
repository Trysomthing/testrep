# Repo instructions

This repo is a single self-contained `index.html` countdown web app (no
build step, no external libraries, no backend).

**Before making any change**, read `REQUIREMENTS.md` — it is the source of
truth for what the app currently does.

**After making any change** that adds, changes, or removes a feature,
update `REQUIREMENTS.md` in the same commit/PR so it never goes stale.
Don't rely on chat history or commit messages to reconstruct requirements —
that file should always be enough on its own.
